1. Pre-Increment

Question: Write a program to show Pre-Increment.

Answer:

#include
int main()
{
    int a=5;
    printf("%d",++a);
    return 0;
}

Output:

6

5. Arithmetic Operations

Question: Write a program to perform Addition, Subtraction, Multiplication, Division and Remainder.

Answer:

#include
int main()
{
    int a=10,b=5;

    printf("Addition=%d\n",a+b);
    printf("Subtraction=%d\n",a-b);
    printf("Multiplication=%d\n",a*b);
    printf("Division=%d\n",a/b);
    printf("Remainder=%d",a%b);

    return 0;
}

Output:

Addition=15
Subtraction=5
Multiplication=50
Division=2
Remainder=0

11. Average of Student Marks

Question: Write a program to calculate average of student marks.

Answer:

#include
int main()
{
    int a=80,b=70,c=90;
    float avg;

    avg=(a+b+c)/3.0;

    printf("%.2f",avg);
    return 0;
}

Output:

80.00
