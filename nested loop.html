Nested Loop Questions

Question 1

Write a C program to print this pattern:

11111
11111
11111

Solution

#include <stdio.h>
int main()
 {
  
  for(int i=1; i<=3; i++) {
 
       for(int j=1; j<=5; j++) {
  
          printf("1");
    
    }
        printf("\n");
   
 }
    return 0;
}

Output

11111
11111
11111
